# TicketBox — Feature Specifications

Thư mục này chứa đặc tả nghiệp vụ chi tiết cho từng tính năng của hệ thống TicketBox theo cấu trúc chuẩn.

## Danh sách Đặc tả (Specs)

- [auth.md](./auth.md): Đặc tả kiểm soát truy cập phân quyền RBAC.
- [payment.md](./payment.md): Đặc tả luồng thanh toán và chống trùng giao dịch (double charge).
- [checkin.md](./checkin.md): Đặc tả luồng soát vé Online và Offline sync.
- [csv_import.md](./csv_import.md): Đặc tả import danh sách khách VIP từ file CSV.
- [ai_bio.md](./ai_bio.md): Đặc tả sinh tiểu sử nghệ sĩ tự động bằng AI.
